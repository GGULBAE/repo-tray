# Repo Tray 0.1.2

직접 만들거나 clone한 프로젝트를 더 쉽게 찾도록 저장소 탐색 범위를 개선했습니다. Homebrew 같은 설치 도구가 내부적으로 사용하는 Git 저장소가 프로젝트 목록에 섞이는 문제를 줄입니다.

## 탐색 개선

- Homebrew·Scoop·Chocolatey의 알려진 설치 경로를 탐색에서 제외합니다.
- 홈 바로 아래의 개발 도구·런타임 관리 폴더와 `node_modules`·패키지 캐시도 제외합니다. 설치·캐시 경로를 **폴더 선택**으로 직접 지정해도 탐색하지 않습니다.
- **기본 폴더에서 찾기** 안내를 사용자 프로젝트 중심으로 정리했습니다. 문서·바탕 화면·외장 드라이브의 프로젝트는 기존처럼 **폴더 선택**으로 직접 지정합니다.
- 경로를 기준으로 구분하며 커밋 작성자나 원격 저장소 소유자로 필터링하지 않습니다. `~/Projects/homebrew`처럼 일반 프로젝트 폴더에 clone한 소스는 같은 이름이어도 탐색합니다. 저장소를 누가 처음 만들었는지 완벽히 판별하는 기능은 아닙니다.

기존 모니터링 등록과 설정을 자동으로 제거하지 않습니다. 디스크의 저장소나 파일을 삭제하거나 이동하지도 않습니다.

## 배포 파일

- Apple Silicon Mac: `Repo-Tray-0.1.2-mac-arm64.zip`
- Intel Mac: `Repo-Tray-0.1.2-mac-x64.zip`
- Windows x64: `Repo-Tray-0.1.2-win-x64.exe`
- 무결성 확인: `SHA256SUMS.txt`

[GitHub Releases](https://github.com/GGULBAE/repo-tray/releases/latest)에서 컴퓨터에 맞는 파일을 받아 설치하세요. Git은 별도로 필요하며 기존 SSH 키나 Git credential helper를 사용합니다. 설치 파일로 사용하는 경우 Node.js는 필요하지 않습니다.

## 알려진 제약

배포물은 **코드 서명되지 않았으며 macOS 공증도 받지 않았습니다.** Gatekeeper 또는 SmartScreen에서 경고나 실행 제한이 나타날 수 있습니다. 앱 내 자동 업데이트는 제공하지 않습니다. 새 버전은 앱을 종료한 뒤 직접 교체하거나 설치하세요.

원격 확인은 fetch만 수행하며 작업 파일 동기화는 사용자가 실행합니다. 자동 clone·commit·push, 브랜치 자동 전환은 포함하지 않습니다. CI와 배포 결과는 해당 버전의 [Actions 실행 기록](https://github.com/GGULBAE/repo-tray/actions)에서 확인할 수 있습니다.
