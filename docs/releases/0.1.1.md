# Repo Tray 0.1.1

Repo Tray의 첫 공개 릴리스입니다. macOS 메뉴바와 Windows 트레이에서 Git 저장소를 확인하고, 다른 컴퓨터에서 push한 변경을 조용히 알려 줍니다.

## 주요 기능

- 여러 저장소를 등록하고 저장소마다 조회 주기를 설정할 수 있습니다. 1시간·5시간·1일 또는 1~10,080분을 직접 지정합니다.
- 백그라운드에서는 원격 상태를 fetch하고, 변경이 있으면 트레이를 빨간색으로 표시합니다. 시스템 알림이나 소리는 보내지 않습니다.
- 새 커밋과 로컬 작업 상태를 확인한 뒤 사용자가 동기화합니다. fast-forward를 지원하며, 이력이 갈라진 경우 merge 또는 rebase를 직접 선택합니다.
- 로컬 수정이 있으면 동기화를 보류합니다. 충돌 파일 확인과 진행 중인 merge/rebase 중단을 지원합니다.
- 창을 닫아도 트레이에 남고 로그인 시 자동 실행을 설정할 수 있습니다. 기존 Git 인증을 사용하므로 별도 Repo Tray 계정은 필요하지 않습니다.

## 저장소 중복과 반복 권한 요청 개선

- 같은 Git 데이터를 공유하는 worktree를 한 저장소 행으로 묶고 실제 작업 폴더를 선택하도록 했습니다. 이미 등록한 그룹의 중복 등록을 막으며, 별도로 clone한 저장소는 각각 유지합니다.
- 같은 실제 폴더의 별칭을 중복으로 표시하지 않습니다. 이전 설정에 등록된 여러 작업 폴더는 자동 삭제하지 않습니다.
- 기본 탐색에서 문서·데스크탑·다운로드·사진·Library·클라우드·외장 볼륨 등 별도 접근 권한이 필요한 경로를 제외합니다. 해당 프로젝트는 **폴더 선택**으로 직접 지정할 수 있습니다.
- 접근이 거부된 경로를 기억해 다음 탐색에서 반복 접근하지 않습니다. 직접 선택하면 다시 시도할 수 있습니다.
- 이미 등록되었거나 macOS 승인을 기다리는 로그인 항목을 실행 때마다 다시 등록하지 않습니다.

## 설치 파일

- Apple Silicon Mac: `Repo-Tray-0.1.1-mac-arm64.zip`
- Intel Mac: `Repo-Tray-0.1.1-mac-x64.zip`
- Windows x64: `Repo-Tray-0.1.1-win-x64.exe`
- 무결성 확인: `SHA256SUMS.txt`

Git을 별도로 설치하고, 모니터링할 프로젝트를 각 컴퓨터에 clone한 뒤 기존 Git 인증으로 fetch할 수 있도록 준비하세요. 설치 파일로 사용하는 경우 Node.js는 필요하지 않습니다.

## 알려진 제약과 검증 범위

현재 배포물은 **코드 서명되지 않았으며 macOS 공증도 받지 않았습니다.** Gatekeeper 또는 SmartScreen에서 경고나 실행 제한이 나타날 수 있습니다. 앱 내 자동 업데이트는 제공하지 않으며 새 버전은 GitHub Releases에서 직접 설치합니다.

자동 clone·commit·push와 브랜치 자동 전환은 포함하지 않습니다. 충돌 파일 편집은 기존 에디터나 Git 클라이언트에서 진행합니다. Bare 저장소는 동기화 대상으로 등록할 수 없습니다.

공개 준비 과정에서 Git·탐색·설정·예약·로그인·릴리스 관련 테스트 **58개**와 Apple Silicon Mac의 개발 앱·패키징 앱 실행 검증을 통과했습니다. worktree 그룹화, 중복 등록 방지, 원격 변경 표시, 명시적 동기화, 로컬 수정 보호, 설정 저장과 트레이 재열기를 확인했습니다. Intel Mac과 Windows의 실제 컴퓨터에서 설치·로그인 자동 시작까지 확인한 것은 아닙니다. macOS·Windows CI의 실행 결과는 [Actions](https://github.com/GGULBAE/repo-tray/actions)에서 확인할 수 있습니다.
